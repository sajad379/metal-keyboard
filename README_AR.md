# Metal Keyboard — النسخة الأولية

هذه ملفات مصدر لتطبيق أندرويد باسم **Metal Keyboard**. الواجهة سوداء والأزرار بيضاء، ويدعم لوحة مفاتيح عربية/إنجليزية أولية مع صفحة للعبارات السريعة قابلة للتعديل.

## مهم
- هذا **مشروع مصدر** وليس ملف APK جاهزًا.
- لا يمكن تثبيت ملفات Kotlin مباشرة؛ يجب بناء المشروع إلى APK باستخدام Android Studio أو بيئة بناء أندرويد متوافقة.
- البناء الكامل على الهاتف ممكن أن يكون صعبًا مع 4 GB RAM فعلية. لا تبدأ تنزيل SDK أو Gradle إذا كان اتصالك ضعيفًا قبل التأكد من توفر الأدوات المطلوبة.
- النسخة أولية: اقتراح الكلمات والتصحيح التلقائي والقاموس العراقي المتقدم غير مضافين بعد. تخطيط لوحة المفاتيح يحتاج اختبارًا على جهاز حقيقي، خصوصًا اتجاه العربية ومقاسات الأزرار.
- لا توجد صلاحية إنترنت في التطبيق، والعبارات السريعة محفوظة محليًا على الجهاز.
- لا تدخل كلمات مرور حساسة في أي كيبورد مخصص إلا إذا كنت تثق بالمصدر وتفهم صلاحياته.

## بناء المشروع
1. افتح مجلد المشروع في Android Studio.
2. اسمح بمزامنة Gradle وتنزيل مكونات Android SDK المطلوبة.
3. اختر Build > Build APK(s).
4. ثبّت APK الناتج على جهازك.
5. افتح Metal Keyboard، اضغط تفعيل الكيبورد، ثم اختره من قائمة لوحات المفاتيح.

## الوظائف الموجودة
- لوحة عربية أولية.
- لوحة إنجليزية أولية.
- تبديل إلى الأرقام والرموز.
- صفحة عبارات سريعة.
- إضافة العبارات وتعديلها من شاشة التطبيق.
- ثيم أسود وأزرار بيضاء.

## التطوير التالي المقترح
- تحسين تخطيط الحروف العربية والإنجليزية بحسب لغة النظام.
- إضافة تخطيط إنجليزي Shift فعلي، وتحسين أزرار المسافة والحذف والإدخال.
- بناء قاموس عراقي محلي مع اقتراحات اختيارية.
- إضافة إعدادات لتغيير حجم الأزرار وتحرير الاختصارات.
